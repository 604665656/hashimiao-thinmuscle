# 薄肌浓度检测仪 · 陪练桌宠

单文件网页小游戏，B站 TOY / GitHub Pages 上架工程仓。成品就是根目录 `index.html`——拷走就能玩，离线、不联网、不依赖 CDN，照片不出设备。

## 玩法

1. **鉴定台**：一屏收完照片与参数（身高 / 体重 / 日常运动量 / 上次健身 / 主攻部位 / 频次器械），也可用「鉴定员当样本」跳过照片；照片只在浏览器本地读取，不上传、不进存档。
2. **四档浓度等级**：0–100 环形分数落到「纸片人 / 薄肌预备役 / 薄肌本肌 / 练过头了」，每档专属立绘、评语与眼镜猫附注。
3. **桌宠陪练**：建档后切到桌宠态，眼镜猫常驻，打字机对白、摸头 / 小鱼干 / 喝水 / 猫签、亲密度与四枚里程碑。
4. **12 周 = 84 个真实自然日**：按 `YYYY-MM-DD` 唯一键，一天只打一次卡（按计划 +3 / 轻量 +1 / 休息 −1），随时可「修改今天」但天数与历史不重复累加；浓度重算等级、曲线与体态。
5. **DIY 训练计划**：六个方向模板可选、逐项打钩记录；猫猫只给引导性、非强制的锻炼 / 饮食 / 恢复建议。互动不写 `days`、不改浓度，绕不过一天一次。
6. **回看**：点 12 格进度条开周小结（7 格日历按真实日期、浓度前后、四项小结、750×1050 本周卡）；档案室可翻 37 张图（22 立绘 + 11 场景 + 4 唱片），带真 sha1 前 7 位与来处，可「换上它」、导出小档案卡、复制深链。
7. **深链与分享**：`?tab=&mode=&suit=`、`?tab=gallery&g=&pick=`、`?tab=week&week=`，只带外观与位置，不含照片与打卡记录；坏参数一律拦下且不污染本机设置。

## 合规边界

- 零外部请求：不联网、无外链、无后端、无 CDN；`file://` 直接双击可玩。
- 照片只在浏览器本地 `FileReader` 读取，**不上传、不进存档、不进分享链接**。
- 所有数据只存本机 `localStorage`；深链只带外观与位置，不带照片与打卡记录。
- B站 TOY 形态按同系列惯例加水印；本仓不含任何平台 SDK 调用。

> 随附的 `README_动作与抠图_诊断修复_20261105232012.md` 是**素材层工程留档**（银魂 8 套立绘的动作层 / 补底 / alpha 抠图修复记录），描述的是出图管线，不是本 HTML 的运行时内容，也不进 Toy / Pages 交付包；这里只作归档说明，避免误读为漏做功能。

## 目录结构

```
index.html            成品（GitHub Pages 入口）
.nojekyll             禁用 Jekyll，保证原样发布
toy/index.html        B站 TOY 入口（与成品逐字节一致）
toy/build_meta.json   上架包元信息（体积 / 哈希 / 静态指标）
icon.png / poster.png B站 TOY 图标与封面（素材来自成品内嵌立绘与真实渲染）
tools/verify.py       22 项静态校验
```

## 复现

```bash
python _prepare_boji.py          # 只读桌面成品 -> 生成 Toy 包 / Pages 根
python boji/tools/verify.py      # 22/22 PASS
python boji/tools/verify.py boji/toy/index.html
python _make_assets_boji.py      # 由真实渲染截图 + 内嵌立绘生成封面 / 图标
```
